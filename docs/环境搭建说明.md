# O2O 智能聚合电商与大模型网关 - 环境搭建与软件安装指南

为了能够顺利开发和运行本项目，您的 Mac 电脑上需要准备好以下几项基础软件。这里为您提供详细的安装与配置方法。

---

## 1. 本地基础开发环境安装

### 🟢 1. JDK 17 (Java 运行环境)
本项目后端使用 Java 开发，建议安装主流的 JDK 17。
* **安装方法**：推荐下载 Oracle 官方安装包直接安装，或者如果您有 Homebrew，可以在终端执行：`brew install openjdk@17`。

### 🟢 2. Maven 3.x (Java 项目构建工具)
用于下载 Java 依赖和编译打包多模块项目。
* **安装方法**：可以前往 Maven 官网下载解压后配置环境变量，或者终端执行：`brew install maven`。

### 🟢 3. Node.js (前端运行环境)
前端使用 Vue3 + TypeScript 开发，必须依赖 Node.js。建议安装 v18 长期支持版 (LTS)。
* **安装方法**：前往 Node.js 官方网站 (https://nodejs.org/) 下载 macOS 版本的 pkg 安装包，双击一路“下一步”安装即可。

### 🟢 4. 开发工具 (IDE) 推荐
* **后端**：IntelliJ IDEA
* **前端**：Visual Studio Code (配合 Vue - Official 插件)

---

## 2. 核心系统中间件安装 (依靠 Docker 一键启动)

本项目依赖的数据库、缓存、消息队列及 Nginx 反向代理等，全部依靠 **Docker** 统一运行，避免弄脏您的 Mac 本地系统。

**我已经为您在当前文件夹下准备好了 `docker-compose.yml` 和配套的 `nginx.conf` 配置文件。** 您只需按照以下简单步骤操作：

### ⚙️ 启动流程：
1. 确保您的 **Docker Desktop** 软件处于打开且正常运行状态。
2. 打开 Mac 自带的“终端 (Terminal)”。
3. 复制并运行下面这行命令，进入您存放当前安装软件的目录：
   ```bash
   cd "/Users/laq/Documents/tidywindow/DesktopOrganizer/AI开发/O2O 智能聚合电商与大模型网关/安装软件"
   ```
4. 复制并运行下面的命令，Docker 将自动读取本文件夹下的 `.yml` 文件并启动所有服务：
   ```bash
   docker-compose up -d
   ```
   > 第一次运行可能需要几分钟时间下载镜像包，请耐心等待。
5. 当终端命令执行完毕后，打开您的 Docker Desktop 界面。点击侧边栏的 **Containers**，您就会看到全部六个软件都已经跑起来了。
   * 后续如果想清理，直接在界面点击该组群的 ⏹️ 停止/删除按钮即可。容器中的数据库及配置数据会自动保存在当前文件夹的 `docker-data` 目录内，不怕丢失。

## 3. 前端部署与静态资源放置说明 (配合 Nginx)

由于我们采用了 **Nginx 同源反向代理部署**，网页的静态文件需要挂载到 Nginx 容器中运行。

1. **前端打包**：
   在您的前端工程根目录下执行编译打包命令（如 `npm run build` 或 `yarn build`），这会在前端工程下生成一个名为 **`dist`** 的打包文件夹。
2. **资源放置**：
   将这个编译生成的 **`dist`** 文件夹，直接复制或移动到本 `安装软件` 目录下。
   * 确保路径为：`/Users/laq/Documents/tidywindow/DesktopOrganizer/AI开发/O2O 智能聚合电商与大模型网关/安装软件/dist/`
   * 此时，目录里应当包含 `index.html` 及 `assets` 静态资源子文件夹。
3. **即时生效**：
   Nginx 容器启动时会自动挂载并读取该 `./dist` 目录。在浏览器直接输入 `http://localhost` 即可秒级打开系统网页！

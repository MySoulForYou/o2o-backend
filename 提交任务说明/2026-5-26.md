# 📝 2026-05-26 提交任务说明

本项目阶段性工作已全部完成，本篇文档对这一周期内完成的后端核心业务开发、安全优化及微服务骨架初始化工作进行总结归档。

## 🛠️ 1. 网关层安全与体验优化 (`o2o-gateway`)
*   **安全清洗**：拦截并清洗客户端传入的请求头，强制剥离敏感信息（如 `X-User-Id`），从根本上防范内部身份伪造与越权攻击。
*   **全局异常转换**：引入 `GatewayExceptionHandler` 拦截器，捕获网关抛出的 `404`、`500`、`503` 及超时等异常，统一格式化为对前端友好的 `Result` JSON 结构返回。

## 📦 2. 公共模块与上下文隔离 (`o2o-common`)
*   **JWT 验签工具**：封装了 `JwtUtils`，用于 Token 的防篡改解密和用户信息解析。
*   **ThreadLocal 隔离**：引入基于 ThreadLocal 的 `UserContext` 上下文及 `UserContextInterceptor` 拦截器，自动向下游微服务透传解析后的 `userId`，实现业务层与 HTTP 报文头的完全解耦。

## 👤 3. 用户模块与收货地址增强 (`o2o-user-service`)
*   **用户注册防脏校验**：新增注册入参的严格正则校验（用户名、密码强度、手机号格式），杜绝垃圾或非法数据直接写入。
*   **手机号唯一索引**：在 `tb_user` 数据库表增加 `phone` 唯一索引限制，并在业务层（Service）补充并发情况下的防重注册检查。
*   **收货地址上限控制**：实现收货地址的增删查及设为默认地址逻辑，并添加 `MAX_ADDRESS_LIMIT = 20` 数量上限安全控制。

## 🛒 4. 购物车微服务初始化 (`o2o-cart-service`)
*   **服务骨架搭建**：独立构建了购物车微服务工程，端口配置为 `8085`。
*   **组件集成**：完成 Nacos 注册中心、MyBatis-Plus、Redis 以及 Springdoc OpenAPI 调试接口的初始化配置。
*   **网关路由匹配**：在网关配置中将 `/api/cart/**` 路径无缝路由分发至该模块。

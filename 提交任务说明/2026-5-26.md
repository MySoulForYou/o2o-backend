
1. 网关层安全与体验优化 (o2o-gateway)：
   - 过滤与清洗客户端请求头，剥离敏感信息（如 X-User-Id），防止头部伪造攻击。
   - 新增 GatewayExceptionHandler，将网关层 404/500/503 及超时等异常，统一格式化为友好 JSON 返回给前端。

2. 公共模块上下文隔离 (o2o-common)：
   - 封装 JwtUtils 工具类，用于令牌的生成与解密。
   - 引入基于 ThreadLocal 的 UserContext 上下文与 UserContextInterceptor 拦截器，自动传递解析后的用户 ID，实现业务层与 HTTP 头的解耦。

3. 用户模块与收货地址增强 (o2o-user-service)：
   - 用户注册：加入用户名、密码和手机号的正则表达式与长度校验（防脏数据注入）。
   - 唯一性限制：数据库表 tb_user 增加 phone 字段唯一索引约束，并在业务层增加手机号防重注册校验。
   - 收货地址：实现收货地址的增删查及设为默认地址逻辑，并添加每个用户最多 20 个地址的数量上限控制。

4. 购物车服务骨架搭建 (o2o-cart-service)：
   - 完成 o2o-cart-service 的基本骨架搭建（使用 8085 端口），完成 Nacos、MyBatis-Plus 和 Redis 的基础配置，并完成网关的路由分发配置。
